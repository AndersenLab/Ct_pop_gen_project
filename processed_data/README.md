## processed_data

This directory contains processed files generated for downstream analyses in the C. tropicalis PopGen manuscript.

### mosdepth_coverage/

Coverage threshold files generated by mosdepth for individual strains.

- `mosdepth_coverage/thresh/*.thresholds.bed`  
  Per-strain coverage threshold files used for downstream coverage-based analyses.

---

### gt_check_only_HDRs/

- `gt_check_only_HDRs/gtcheck_onlyHDR.tsv`  
  Pairwise genetic similarity results calculated using HDR regions only.

---

### gt_check_no_HDRs/

- `gt_check_no_HDRs/gtcheck_noHDR.tsv`  
  Pairwise genetic similarity results calculated excluding HDR regions.

---

### genomic_bins/

- `genomic_bins/ONT_NIC58_1kb_bins.bed`  
  Genomic bin definitions for the NIC58 reference genome in 1 kb windows.

---

### gene_enrichment/

- `gene_enrichment/CT_chromosome_domains.tsv`
  Chromosome domains of NIC58 used for definiing chromosome arms, centers, and tips

- `gene_enrichment/N2_NIC58_orthogroups.tsv`
  OrthoFinder-identified orthologs between *C. elegans* N2 and *C. tropicalis* NIC58

- `gene_enrichment/NIC58_IPR_allApps_20251202.tsv`
  InterProScan annotation results output from `../scripts/gene_enrichment/InterProScan.sh`

- `gene_enrichment/c_elegans.PRJNA13758.WS283.csq.PCfeaturesOnly.longest.gff3`
  Longest isoform protein-coding gene models of *C. elegans* N2 strain  

- `gene_enrichment/c_tropicalis.NIC58_20251002.csq.longest.PC.noMtDNA.fa`
  NIC58 proteome used for InterProScan annotation in `../scripts/gene_enrichment/InterProScan.sh`

- `gene_enrichment/c_tropicalis.NIC58_20251002.csq.longest.gff3`
  Longest isoform protein-coding gene models of *C. tropicalis* NIC58 strain

---

### Ct_admixture/

Processed ADMIXTURE output files across multiple K values and replicate seeds.

- `Ct_admixture/seeds.txt`

### Dxy_LAC/

Input and output files for population genetic analyses among relatedness groups.

- `Dxy_LAC/pop_file_lineage.txt`  
  Population assignment file used for calculating pairwise Dxy, FST, nucleotide diversity (π), Watterson’s θ, and Tajima’s D among relatedness groups.

#### Dxy_LAC/results/

- `Dxy_LAC/results/Ct_Dxy__dxy.txt`  
  Pairwise Dxy estimates among relatedness groups.

- `Dxy_LAC/results/Ct_Dxy__pi.txt`  
  Nucleotide diversity (π) estimates for relatedness groups.

- `Dxy_LAC/results/Ct_Dxy__tajima_d.txt`  
  Tajima’s D estimates for relatedness groups.

- `Dxy_LAC/results/Ct_Dxy__watterson_theta.txt`  
  Watterson’s θ estimates for relatedness groups.

### HDR_stats/

Files used to summarize C. tropicalis HDRs, heterozygous-like SNV signals, one-to-one orthologs, and four-fold degenerate site diversity:

- `Ct_soft_filtered_hets.TableS7_HDR_ranges.bed`: HDR intervals from Table S7 in BED format  
- `Ct_soft_filtered_hets.het_counts_per_site.tsv`: per-site heterozygous genotype counts from the soft-filtered VCF  
- `Ct_soft_filtered_hets.SNV_sites.bed`: SNV site coordinates in BED format  
- `Ct_soft_filtered_hets.HDR_site_ids.txt`: SNV sites overlapping HDR intervals  
- `Ct_soft_filtered_hets.het_counts_per_site.HDR_labeled.tsv`: per-site heterozygous genotype counts labeled as HDR or non-HDR  
- `N2_NIC58_1to1_orthologs.tsv`: one-to-one orthologs between C. elegans N2 and C. tropicalis NIC58  

#### HDR_stats/pi_theta_d_1to1_4fold/*
Diversity estimates calculated from variable SNVs at four-fold degenerate sites in one-to-one C. elegans-C. tropicalis orthologs
